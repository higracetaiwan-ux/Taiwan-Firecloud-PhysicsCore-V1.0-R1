# Taiwan Firecloud PhysicsCore V1.0 — Migration from V8

## Historical baseline
PhysicsCore V1.0-R1 was refactored from the Taiwan Firecloud V8.4.16.7 code baseline.

## Documentation policy
Individual V8.x release notes, version notes, and V8 performance-note documents are intentionally excluded from the V1.0 deploy package. They belong to the archived V8 development line and are not part of the active V1.0 documentation set.

## What remains intentionally compatible in R1
R1 still retains selected V8-era provider, radiative-transfer, and runtime components as compatibility infrastructure while the PhysicsCore V1.0 contracts and module boundaries are introduced incrementally.

## Architecture migration direction
The V1.0 line replaces legacy single-score / fixed-REZ physics with the frozen PhysicsCore V1.0 architecture: CloudScene, Canvas-specific Sun→CloudBase rays, DirectSolarFraction, dynamic ray-derived REZ diagnostics, six-band optical paths, separate Formation / Viewing / Twilight Glow results, dependency-aware uncertainty, Peak Window, and a separate Decision Layer.

## Legacy diagnostic geometry
Legacy distance bands may remain available for measurement, visualization, historical comparison, and regression diagnostics. They are not V1.0 hard radiative-transfer boundaries.
